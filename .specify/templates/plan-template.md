## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Evaluar `.specify/memory/constitution.md` y registrar evidencia o «no aplica» justificado:

- **I — Durable**: fuente de verdad, proyecciones reconstruibles e intención previa al efecto.
- **II — Idempotencia**: requestId/ledger, conflictos, ventanas de caída y cierre/reapertura.
- **III — Autoridad**: origen del actor, revisión/consumo separados y ninguna promoción automática.
- **IV — Seguridad**: confianza, validación de entradas/rutas y exposición acotada de datos sensibles.
- **V — Contratos**: servicios comunes, APIs públicas y alternativa más simple para complejidad nueva.
- **Compatibilidad**: versiones realmente verificadas; migración, backup y fixture si cambia el esquema.
- **Calidad**: pruebas según impacto, `npm run check`, `npm test`, smoke y aceptación TUI aplicables.
- **Autorización**: gate de entrada de `specs/ROADMAP.md`, spec aprobada y excepciones registradas.
  Antes de implementar: plan revisado y método elegido por el humano.

No cerrar gates con fallos pendientes. Registrar bloqueos y la decisión humana necesaria;
esta planificación no autoriza implementación ni cambia estados de fase.
